# Assignment #5 — JavaScript Basics

A small multi-page website demonstrating JavaScript fundamentals, DOM manipulation, and browser events.

## Pages
- `index.html`: task navigation
- `task0.html`–`task8.html`: all assignment tasks
- `css/style.css`: shared responsive styling
- `js/app.js`: task interactions

## Run locally
Open `index.html` in a browser. Task 0 displays the required greeting alert; the browser console shows the student and group details. Use the navigation bar to open each task.

## Publish
In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. Wait for the published URL to appear in the Pages section.
